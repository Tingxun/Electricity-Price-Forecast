# 基于epftoolbox的湖北省电价预测实验方案

## 1. 实验目标

利用epftoolbox中的先进预测模型，结合湖北省能源数据集，开发高精度的电价预测系统。

**主要目标**:
- 实现未来24小时电价预测（日前市场）
- 预测精度达到MAPE < 10%
- 建立可复现的预测流程
- 对比不同模型的预测性能

## 2. 可用模型分析

### 2.1 epftoolbox提供的模型

epftoolbox提供了两个先进的电价预测模型：

#### 2.1.1 LEAR模型 (LASSO-Enhanced AutoRegressive)
- **类型**: 线性回归模型 + LASSO正则化
- **特点**: 
  - 基于自回归框架
  - 自动特征选择
  - 计算效率高
  - 适合基准模型建立

#### 2.1.2 DNN模型 (Deep Neural Network)
- **类型**: 深度神经网络
- **特点**:
  - 多层神经网络结构
  - 自动特征学习能力
  - 适合复杂非线性关系建模
  - 支持超参数优化

### 2.2 模型对比优势

| 模型 | 优势 | 适用场景 |
|------|------|----------|
| LEAR | 计算快、可解释性强 | 基准模型、快速部署 |
| DNN | 预测精度高、非线性建模 | 高精度要求、复杂模式识别 |

## 3. 实验设计

### 3.1 数据预处理流程

#### 3.1.1 数据清洗
1. **缺失值处理**:
   - 价格数据：时间序列插值
   - 气象数据：多源数据融合
   - 负荷数据：前后时刻插值

2. **异常值处理**:
   - 识别价格0值和极端高价
   - 基于统计方法检测异常
   - 合理替换或标记异常值

#### 3.1.2 特征工程
1. **时间特征**:
   - 小时、星期、月份、季节
   - 节假日标识
   - 工作日/周末标识

2. **滞后特征**:
   - 历史价格滞后（1-24小时）
   - 历史负荷滞后
   - 滚动统计特征（均值、标准差等）

3. **外部特征**:
   - 系统负荷预测和实际值
   - 新能源负荷数据
   - 水电出力情况
   - 气象数据（温度、湿度等）
   - 联络线计划

#### 3.1.3 数据标准化
- 使用Z-score标准化
- 保持时间序列特性
- 确保模型训练稳定性

### 3.2 实验设置

#### 3.2.1 数据集划分
- **训练集**: 2024年4月16日 - 2024年12月31日
- **验证集**: 2025年1月1日 - 2025年2月28日
- **测试集**: 2025年3月1日 - 2025年3月28日

#### 3.2.2 评估指标
1. **主要指标**:
   - MAE (平均绝对误差)
   - RMSE (均方根误差)
   - MAPE (平均绝对百分比误差)
   - sMAPE (对称平均绝对百分比误差)

2. **辅助指标**:
   - MASE (平均绝对标度误差)
   - RMAE (相对平均绝对误差)

#### 3.2.3 基准模型
- 朴素预测（昨日同期价格）
- 移动平均模型
- 季节性ARIMA模型

```python
def train_lear_model(data, calibration_window=728):
    """训练LEAR模型"""
    from epftoolbox.models import LEAR
    model = LEAR(calibration_window=calibration_window)
    model.fit(data)
    return model

def train_dnn_model(data, hyperparameters):
    """训练DNN模型"""
    from epftoolbox.models import DNN
    model = DNN(**hyperparameters)
    model.fit(data)
    return model
```

### 5.3 评估框架
```python
def evaluate_model(model, test_data):
    """模型评估函数"""
    from epftoolbox.evaluation import MAE, RMSE, MAPE
    
    predictions = model.predict(test_data)
    actual = test_data['price']
    
    mae = MAE(predictions, actual)
    rmse = RMSE(predictions, actual)
    mape = MAPE(predictions, actual)
    
    return {'MAE': mae, 'RMSE': rmse, 'MAPE': mape}
```
