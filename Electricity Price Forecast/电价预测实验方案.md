# 湖北省日前电价预测实验方案

## 1. 实验目标

利用机器学习方法，结合湖北省能源数据集，开发高精度的日前电价预测系统。

**主要目标**:
- 实现未来24小时日前电价预测（T+1时刻的24点实时价格）
- 预测精度达到MAPE < 10%
- 建立模块化、可复现的预测流程
- 对比不同模型的预测性能

**预测场景定义**:
- 位于T时间点，使用以下数据进行预测：
  - **历史实时数据**: T-2及之前的实时市场边界信息和实时价格数据
  - **日前披露数据**: T日披露的T+1及以前的日前市场边界信息和日前价格数据
- **预测目标**: T+1时刻的24点实时价格

## 4. 特征工程方案

### 4.1 特征分类

#### 4.1.1 时间特征
- 小时 (0-23)
- 星期几 (0-6)
- 月份 (1-12)
- 是否工作日 (0/1)
- 是否节假日 (0/1)
- 季节 (1-4)

#### 4.1.2 历史滞后特征（基于T-2及之前数据）
- 价格滞后: T-1, T-2, T-3, T-7（同一小时）
- 负荷滞后: T-1, T-2的实时负荷
- 滚动统计: 过去7天同一小时的均值、标准差、最大值、最小值

#### 4.1.3 日前披露特征（T日披露T+1）
- 日前负荷预测（24点）
- 日前新能源负荷预测（24点）
- 日前水电出力计划（24点）
- 日前联络线计划（24点）
- 日前非市场化机组计划（24点）
- 天气状况聚类标签（由气象数据聚类得到）

#### 4.1.4 衍生特征
- 供需差: 负荷 - (新能源 + 水电 + 非市场化机组)
- 价格变化率: (当前价格 - 前一时刻价格) / 前一时刻价格
- 日前-实时偏差历史统计

```python
# 伪代码示例
def build_features(T):
    """
    在T时间点构建特征
    """
    # 1. 加载历史实时数据 (T-2及之前)
    historical_data = load_historical_data(end_date=T-2)
    
    # 2. 加载日前披露数据 (T日披露T+1)
    day_ahead_data = load_day_ahead_data(forecast_date=T+1, disclosure_date=T)
    
    # 3. 构建时间特征
    time_features = create_time_features(target_date=T+1)
    
    # 4. 构建滞后特征
    lag_features = create_lag_features(historical_data, lags=[1, 2, 3, 7])
    
    # 5. 构建滚动统计特征
    rolling_features = create_rolling_features(historical_data, windows=[7, 14, 30])
    
    # 6. 合并所有特征
    features = merge_features([time_features, lag_features, rolling_features, day_ahead_data])
    
    return features
```

### 4.3 气象数据聚类分析

由于原始气象数据存在完整性问题，不直接作为模型输入特征，而是采用聚类分析方法提取天气模式信息。

#### 4.3.1 聚类方法
- **K-Means聚类**: 基于温度、湿度、风速等特征进行无监督聚类
- **高斯混合模型(GMM)**: 考虑天气特征的概率分布特性
- **层次聚类**: 探索天气类型的层次结构

#### 4.3.2 聚类特征选择
- 日平均温度
- 日最高/最低温度
- 日平均湿度
- 日平均风速
- 天气状况编码（晴、阴、雨等）

### 4.4 特征优化方法

由于模型输入特征维度较高，需要采用特征优化方法提升模型性能和训练效率。

#### 4.4.1 特征选择方法

**过滤法 (Filter Methods)**:
- 相关系数分析: 剔除与目标变量相关性低的特征
- 互信息法: 基于信息论筛选重要特征
- 方差阈值: 剔除方差过低的常数特征

**包装法 (Wrapper Methods)**:
- 递归特征消除 (RFE): 递归剔除弱特征
- 前向选择: 逐步添加最优特征
- 后向消除: 逐步剔除最弱特征

**嵌入法 (Embedded Methods)**:
- LASSO正则化: 自动进行特征选择
- 树模型特征重要性: 基于XGBoost/LightGBM的特征重要性排序
- Elastic Net: 结合L1和L2正则化

#### 4.4.2 混合优化策略（特征+超参数联合优化）

**二进制编码表示**:
```
染色体编码结构:
[特征选择位 | 超参数编码位]

特征选择位 (二进制):
- 每个特征对应1位 (0: 不使用, 1: 使用)
- 例如: 100101... 表示选择第1、4、6个特征

超参数编码位 (二进制/实数):
- 学习率、树深度、正则化系数等
- 采用二进制编码或实数编码
```

**粒子群优化算法 (PSO)**:
```python
# 伪代码示例
def pso_feature_hyperparameter_optimization(X, y, model_class):
    """
    使用PSO进行特征和超参数联合优化
    """
    def fitness_function(particle):
        # 解码粒子
        feature_mask = decode_feature_bits(particle[:n_features])
        hyperparams = decode_hyperparameter_bits(particle[n_features:])
        
        # 选择特征
        X_selected = X[:, feature_mask]
        
        # 训练模型
        model = model_class(**hyperparams)
        scores = cross_val_score(model, X_selected, y, cv=5, scoring='neg_mse')
        
        # 返回负MSE（PSO求最大值）
        return np.mean(scores)
    
    # PSO参数
    n_particles = 30
    n_iterations = 100
    
    # 初始化粒子群
    particles = initialize_particles(n_particles, n_features + n_hyperparams)
    velocities = initialize_velocities(n_particles, n_features + n_hyperparams)
    
    # PSO迭代
    for iteration in range(n_iterations):
        for i, particle in enumerate(particles):
            # 评估适应度
            fitness = fitness_function(particle)
            
            # 更新个体最优
            if fitness > pbest_fitness[i]:
                pbest[i] = particle.copy()
                pbest_fitness[i] = fitness
            
            # 更新全局最优
            if fitness > gbest_fitness:
                gbest = particle.copy()
                gbest_fitness = fitness
        
        # 更新速度和位置
        for i in range(n_particles):
            velocities[i] = (w * velocities[i] + 
                           c1 * random() * (pbest[i] - particles[i]) +
                           c2 * random() * (gbest - particles[i]))
            particles[i] = particles[i] + velocities[i]
    
    # 解码最优解
    best_features = decode_feature_bits(gbest[:n_features])
    best_hyperparams = decode_hyperparameter_bits(gbest[n_features:])
    
    return best_features, best_hyperparams
```

**遗传算法 (GA)**:
```python
# 伪代码示例
def ga_feature_hyperparameter_optimization(X, y, model_class):
    """
    使用遗传算法进行特征和超参数联合优化
    """
    def fitness_function(chromosome):
        feature_mask = decode_feature_bits(chromosome[:n_features])
        hyperparams = decode_hyperparameter_bits(chromosome[n_features:])
        
        X_selected = X[:, feature_mask]
        model = model_class(**hyperparams)
        scores = cross_val_score(model, X_selected, y, cv=5, scoring='neg_mse')
        
        # 惩罚项: 特征数量过多
        penalty = alpha * np.sum(feature_mask) / n_features
        return np.mean(scores) - penalty
    
    # GA参数
    population_size = 50
    n_generations = 100
    crossover_rate = 0.8
    mutation_rate = 0.1
    
    # 初始化种群
    population = initialize_population(population_size, n_features + n_hyperparams)
    
    # 进化迭代
    for generation in range(n_generations):
        # 评估适应度
        fitness_scores = [fitness_function(chrom) for chrom in population]
        
        # 选择
        selected = tournament_selection(population, fitness_scores)
        
        # 交叉
        offspring = crossover(selected, crossover_rate)
        
        # 变异
        offspring = mutate(offspring, mutation_rate)
        
        # 更新种群
        population = offspring
    
    # 返回最优解
    best_chromosome = population[np.argmax(fitness_scores)]
    return decode_solution(best_chromosome)
```

```python
# 伪代码示例
from skopt import BayesSearchCV

def bayesian_optimization(X, y, model_class, param_space):
    """
    贝叶斯优化超参数
    """
    opt = BayesSearchCV(
        estimator=model_class(),
        search_spaces=param_space,
        n_iter=50,
        cv=5,
        scoring='neg_mean_squared_error',
        random_state=42
    )
    opt.fit(X, y)
    return opt.best_params_, opt.best_score_
```

```python
def optimize_pipeline(X, y):
    """
    完整的特征和超参数优化流程
    """
    # 步骤1: 初步特征筛选（过滤法）
    X_filtered = filter_features(X, y, threshold=0.05)

        X_selected, y, XGBoostRegressor, 
        param_space=create_param_space(best_params)
    )
    
    return best_features, final_params
```

```python
            evaluate_predictions(predictions, features.test_y)
```

## 8. 评估指标

### 8.1 主要指标
- **MSE**: 均方误差 (Mean Squared Error)
  - 公式: $MSE = \frac{1}{n}\sum_{i=1}^{n}(y_i - \hat{y}_i)^2$
  - 用途: 衡量预测值与真实值的平方差平均值，对大误差惩罚较重
  
- **MAE**: 平均绝对误差 (Mean Absolute Error)
  - 公式: $MAE = \frac{1}{n}\sum_{i=1}^{n}|y_i - \hat{y}_i|$
  - 用途: 衡量预测值与真实值的绝对差平均值，对异常值更稳健
  
- **sMAPE**: 对称平均绝对百分比误差 (symmetric Mean Absolute Percentage Error)
  - 公式: $sMAPE = \frac{100\%}{n}\sum_{i=1}^{n}\frac{|y_i - \hat{y}_i|}{(|y_i| + |\hat{y}_i|)/2}$
  - 用途: 衡量相对误差，对称处理避免分母为零问题，适合电价预测场景

### 8.2 辅助指标
- **RMSE**: 均方根误差 (Root Mean Squared Error)
  - 公式: $RMSE = \sqrt{MSE}$
  - 用途: 与原始数据同量纲，便于解释
  
- **MAPE**: 平均绝对百分比误差 (Mean Absolute Percentage Error)
  - 公式: $MAPE = \frac{100\%}{n}\sum_{i=1}^{n}|\frac{y_i - \hat{y}_i}{y_i}|$
  - 注意: 当真实值接近零时可能不稳定，sMAPE更为稳健

### 8.3 分时段评估
- **MSE/MAE/sMAPE per hour**: 各小时的独立指标
- **峰时段评估**: 关注用电高峰期的预测准确性
- **谷时段评估**: 关注用电低谷期的预测准确性
