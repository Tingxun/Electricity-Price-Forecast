# 电价预测数据分析报告

## 1. 概述

本报告基于湖北省电力现货市场2024年4月16日至2025年3月27日的实际运行数据，对日前出清价格进行全面探索性数据分析（EDA），旨在揭示价格形成机制、主要驱动因素、时间规律、异常模式及潜在建模难点，为后续短期电价预测模型的特征工程、模型选择与异常处理提供科学依据。

### 1.1 数据来源与范围
- 数据文件：市场边界_出清价格总表.csv
- 时间粒度：1小时（24点/天）
- 覆盖周期：2024-04-16 00:00 至 2025-03-27 00:00（共326天，7824条记录）
- 核心目标变量：平均出清价格-日前（元/MWh）

### 1.2 分析目标
1. 刻画出清价格的分布特征、季节性、日内模式与周内规律
2. 量化负荷、新能源出力、水电、联络线、非市场化机组等关键因素对价格的影响强度与方向
3. 识别极端价格（尖峰/负价）发生场景与驱动因素
4. 评估变量间相关性与多重共线性，为特征选择与降维提供依据
5. 挖掘滞后效应、多时间尺度特征及随机森林特征重要性

### 2.2 分布特征分析

1. **右偏分布验证**：均值（345.45）显著小于中位数（366.41），表明价格分布存在明显右偏，大量低价样本拉低了整体均值，而中位数更能代表典型价格水平。
2. **尾部特征**：价格范围0–1004.26元/MWh，标准差（171.68）接近均值的50%，说明价格波动极强，存在显著的尖峰厚尾特征。
3. **缺失值模式**：168条缺失记录（占比2.15%）可能集中在特定时段（如系统故障或数据传输中断），后续需检查缺失值的时间分布是否存在系统性偏差。

- 右偏分布反映了电力市场的典型特征：大部分时段供需相对平衡，价格维持在合理区间；少数时段因极端负荷、新能源出力骤降或机组故障导致价格飙升。
- 极低价格（接近0）可能出现在新能源大发且负荷低谷时段，市场出现负电价现象，发电企业为避免弃能接受低价甚至倒贴。
- 极端高价（>800元/MWh）通常发生在夏季/冬季用电高峰、新能源出力不足、跨省输电受限等多重因素叠加的紧张场景。

**建模启示**：
- 需使用鲁棒性模型（如分位数回归、随机森林）处理极端值影响
- 考虑对价格进行对数变换或使用分桶编码降低尾部噪声
- 缺失值可采用时间序列插值（如线性插值、 Prophet 填充）或标记为特殊类别

## 3. 时间维度规律分析

### 3.1 全周期价格走势
![出清价格时序图（2024-04-16至2025-03-27）](./可视化图表/多时间尺度电价分析-1.png)

1. **趋势性检验**：通过观察时序图可发现价格存在明显的季节性趋势，而非随机游走过程，适合使用季节性时间序列模型（如SARIMA、Prophet）进行建模。
2. **波动聚类**：价格波动呈现集群特征，高波动时段与低波动时段交替出现，符合ARCH/GARCH类模型的适用条件。
3. **异常点识别**：图中可见多个尖峰点（如2024年9月、2024年10月），需进一步分析这些极端价格发生的具体日期和驱动因素。

### 3.2 季节性分析
![出清电价季节性分析](./可视化图表/电价季节性分析.png)

1. **月份维度**：
   - 7–9月价格均值显著高于其他月份，可能与夏季空调负荷高峰、水电来水减少有关
   - 10–12月价格标准差最大，反映冬季取暖负荷与新能源出力不确定性叠加导致的高波动性
   - 3–5月价格最为平稳，供需矛盾相对缓和

2. **小时维度**：
   - 0–8时和15–23时存在两个明显的价格高峰，对应早间起床和晚间用电高峰
   - 9–14时价格处于低谷，与光伏出力高峰时段高度重合

- **夏季高价**：湖北省夏季高温天气导致空调负荷激增，同时长江流域7–9月进入枯水期，水电出力下降，火电调峰压力增大，推高电价。
- **冬季高波动**：冬季取暖负荷与新能源出力（尤其是风电）的随机性叠加，导致供需平衡难度加大，价格波动剧烈。
- **午间低谷**：光伏出力在中午时段达到峰值，大量清洁电力注入市场，压低了整体电价水平。

### 3.3 日内与周内模式
![小时-星期电价热力图](./可视化图表/小时-星期电价热力图.png)

1. **日内模式**：
   - 价格呈现明显的双峰分布，早高峰（0–8时）和晚高峰（15–23时）价格分别比午间低谷高出约30%和40%
   - 午间低谷（9–14时）价格均值仅为280元/MWh左右，远低于全天平均水平
   - 日内价格波动幅度可达200–300元/MWh，表明电力市场的日内供需变化剧烈

2. **周内模式**：
   - 工作日（周一至周五）价格均值略高于周末（周六至周日），差异约为5–10%
   - 周末午间低谷价格更低，可能与工业负荷下降有关
   - 周末早高峰价格峰值不如工作日明显，反映居民用电模式的差异

- **早高峰**：居民起床、早餐准备、工业开工等因素导致负荷快速上升，而光伏出力尚未达到峰值，供需紧张推高价格。
- **午间低谷**：光伏出力达到全天峰值，同时工业负荷相对稳定，电力供过于求导致价格下跌。
- **晚高峰**：居民晚餐、照明、空调使用叠加工业生产，负荷达到全天峰值，而光伏出力逐渐下降，供需矛盾加剧。
- **周末效应**：周末工业负荷下降，整体用电需求降低，价格中枢下移。

**建模启示**：
- 需构建小时级别的时间特征（如小时sin/cos变换、高峰时段哑变量）捕捉日内模式
- 引入工作日/周末哑变量区分周内不同时段的价格行为
- 考虑使用分时段建模策略，针对早高峰、午间低谷、晚高峰分别训练模型

## 4. 关键驱动因素分析

### 4.1 负荷与价格关系
![系统负荷与出清电价散点图](./可视化图表/系统负荷与出清电价散点图-1.png)
![系统负荷与出清电价散点图](./可视化图表/系统负荷与出清电价散点图-2.png)

1. **非线性关系**：负荷与价格呈现明显的非线性正相关，当负荷超过35,000 MW时，价格弹性显著增大（斜率从约0.01变为约0.05）
2. **异方差性**：高负荷时段价格离散度明显增大，说明在供需紧张时，其他因素（如新能源出力、机组可用性）对价格的影响更为显著
3. **阈值效应**：35,000 MW可视为供需平衡的临界点，超过该值后市场进入紧张状态，价格对负荷变化更加敏感

- **负荷阈值效应**：当负荷超过35,000 MW时，湖北省电力系统的备用容量不足，需要调用成本更高的调峰机组（如燃气轮机），导致电价飙升。
- **供需紧张传导**：高负荷时段往往伴随新能源出力不确定性（如夜间光伏出力为0），进一步加剧供需矛盾，推高价格。
- **市场力发挥**：在供需紧张时，发电企业可能利用市场力抬高价格，尤其是当少数机组掌握关键调峰资源时。

**建模启示**：
- 需引入负荷的非线性变换（如平方项、分段函数）捕捉阈值效应
- 考虑构建供需紧张指数（如负荷/备用容量比）作为特征
- 对高负荷时段和低负荷时段采用不同的建模策略

### 4.2 新能源出力影响
![新能源出力分布与多时间尺度折线图](./可视化图表/新能源出力分布与多时间尺度折线图.png)

1. **光伏出力特征**：
   - 光伏出力呈现明显的日间峰值，90%以上的出力集中在9–17时
   - 光伏出力与价格的负相关系数约为-0.36，是所有特征中最强的负相关
   - 光伏出力的日际波动相对较小，主要受天气（云量、辐照）影响

2. **风电出力特征**：
   - 风电出力随机性更强，日变化模式不如光伏明显
   - 风电出力与价格的负相关系数约为-0.12，远弱于光伏
   - 风电出力的日际波动较大，受风速、风向变化影响显著
   
- **光伏价格压制**：光伏出力高峰与午间负荷低谷叠加，导致电力供过于求，发电企业为了消纳光伏电力不得不降低报价，甚至出现负电价。
- **风电影响较弱**：风电出力相对分散，且夜间出力占比较高，与负荷高峰时段有一定重叠，因此对价格的负向压制作用不如光伏明显。
- **新能源消纳压力**：湖北省新能源装机容量快速增长，但电网调节能力有限，导致新能源大发时段价格下跌，而新能源出力不足时段价格飙升。

**建模启示**：
- 需构建光伏/风电出力的时间特征（如出力时段、爬坡率）
- 考虑引入新能源预测误差作为特征，反映出力不确定性
- 对新能源大发时段和出力不足时段采用不同的建模策略

## 7. 主要结论与建模启示

1. **光伏是价格最强负向驱动因素**，中午光伏爬坡是形成午间低谷的主因
2. **高峰负荷是尖峰价格核心触发条件**，负荷>35GW时价格弹性显著增大
3. **水电–非市场机组–联络线存在严重共线性**，建模时需降维或仅保留代表性变量
4. **价格具有显著短时滞后依赖**（1–6小时最强），建议使用LSTM/TCN/Transformer等时序模型
5. **多时间尺度特征明显**，日内双峰、周末低谷、夏季抬升，推荐分时段/分季节建模策略
6. **异常价格成因复杂**，需结合异常检测、鲁棒损失函数或分位数回归处理尾部风险

## 8. 特征工程与后续工作建议

### 8.1 特征工程详细方案

**时间特征工程**：
1. **小时编码**：
   - 对小时进行sin/cos变换，捕捉日内周期性：
     ```python
     df['hour_sin'] = np.sin(2 * np.pi * df['hour'] / 24)
     df['hour_cos'] = np.cos(2 * np.pi * df['hour'] / 24)
     ```
   - 构建高峰时段哑变量：0–8时和15–23时标记为1，其余时段为0

2. **日期特征**：
   - 提取星期几、节假日、工作日/周末等特征
   - 构建月份sin/cos变换，捕捉季节性周期

**新能源特征工程**：
1. **出力占比**：
   - 风光总出力占比 = (风电出力 + 光伏出力) / 系统负荷
   - 光伏/风电出力占比 = 光伏出力 / (光伏出力 + 风电出力)

2. **爬坡率**：
   - 光伏爬坡率 = 光伏出力(t) - 光伏出力(t-1)
   - 风电爬坡率 = 风电出力(t) - 风电出力(t-1)

3. **预测误差**：
   - 光伏预测误差 = 光伏实际出力 - 光伏日前预测
   - 风电预测误差 = 风电实际出力 - 风电日前预测

**供需特征工程**：
1. **净负荷**：净负荷 = 系统负荷 − (风电出力 + 光伏出力 + 水电出力)
2. **供需紧张指数**：供需紧张指数 = 净负荷 / 联络线计划
3. **备用容量**：备用容量 = 系统最大发电能力 - 系统负荷

**滞后与滚动特征**：
1. **滞后项**：引入价格、负荷、光伏出力前1–12小时的滞后项
2. **滚动统计量**：计算1h、6h、24h窗口内的均值、标准差、最大/最小值

### 8.2 模型构建建议

**模型选择策略**：
1. **基准模型**：使用XGBoost、LightGBM等梯度提升树模型作为基准
2. **时序模型**：尝试使用LSTM、TCN、Transformer等时序模型捕捉时间依赖
3. **鲁棒模型**：使用分位数回归、极端梯度提升（XGBoost with quantile loss）处理极端价格
4. **集成模型**：融合多种模型的预测结果，提高整体性能

**分场景建模**：
1. **分季节建模**：分别训练春季、夏季、秋季、冬季四个模型
2. **分时段建模**：针对早高峰、午间低谷、晚高峰分别训练模型
3. **分供需场景建模**：针对供需紧张、供需平衡、供过于求三种场景分别建模

### 8.3 后续重点研究方向

1. **数据融合**：
   - 引入天气数据（辐照、风速、气温）增强新能源出力预测精度
   - 接入电网拓扑、机组状态等数据，提高模型解释力

2. **异常处理**：
   - 开展极端价格场景下的分位数回归与生成式异常检测
   - 构建异常价格识别与预警系统

3. **多时间尺度预测**：
   - 构建日前–实时多源融合预测框架
   - 研究短期（1–6小时）、中期（1–7天）、长期（1–30天）电价预测方法

4. **市场机制研究**：
   - 分析电力市场规则对价格形成的影响
   - 研究新能源消纳、跨省交易等政策对电价的影响

5. **可视化与解释性**：
   - 构建电价预测可视化平台，展示预测结果与关键影响因素
   - 使用SHAP、LIME等工具解释模型预测结果，提高透明度
